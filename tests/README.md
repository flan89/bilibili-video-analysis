# 测试与行为案例

`tests/` 同时保存 Tool 的确定性测试和 Skill 的 Agent 行为评估数据。默认测试不访问 B站网络。

## 1. 测试类型

| 类型 | 位置 | 目的 | 默认执行 |
|---|---|---|---|
| 单元测试 | `unit/` | 验证 Tool、适配器、模型和纯计算模块 | 是 |
| 集成测试 | `integration/` | 验证真实 B站接口兼容性 | 否 |
| Skill 行为案例 | `skill-cases.json`、`agent-runs/` | 检查 Agent 是否正确规划、取数、分析和停止 | 部分 |
| 路由案例 | `routing-cases.json` | 检查任务理解和数据计划的代表性输入 | 数据模型检查 |

## 2. 单元测试

执行全部单元测试：

```bash
npm test
```

执行指定测试：

```bash
npm test -- get-comments
npm test -- routing-cases
```

单元测试使用固定样例，重点覆盖：

- Tool 成功、部分成功、缺失和失败；
- B站原始数据的解析与标准化；
- 多P、分页、重复数据和范围读取；
- 字幕清理、分块、缓存和本地语音转写包装；
- 关键帧抽取、覆盖范围和媒体失败；
- 运行入口、环境提示和数据模型；
- Agent 运行记录与评估规则。

新增数据 Tool 时，至少应提供正常、异常和不完整场景的固定样例测试。

## 3. 真实网络集成测试

真实网络测试默认关闭：

```bash
RUN_BILIBILI_INTEGRATION=1 npm run test:integration
```

可以按需设置测试视频和本机登录状态，具体变量见 [`../docs/development-guide.md`](../docs/development-guide.md)。

集成测试可能因为视频失效、登录状态、地区限制、平台风控或接口变化而失败。它用于发现兼容性问题，不能替代固定样例测试。

Cookie 不得写入固定样例、日志或提交记录。

## 4. Skill 行为案例

`skill-cases.json` 描述代表性的真实任务和期望行为，例如：

- 必须调用哪些 Tool；
- 默认不能调用哪些 Tool；
- 最大调用次数；
- 是否需要来源时间或编号；
- 数据缺失时是否声明能力缺口；
- 回答中必须出现或不能出现的结论；
- 需要另行进行语义判断的质量维度。

`agent-runs/*.json` 保存 Agent 执行案例后的 Tool 调用轨迹、最终回答和评估状态。真实运行结果默认不提交仓库。

执行结构化验证：

```bash
npm run agent-run:verify
```

保存新的运行结果：

```bash
npm run agent-run:dump -- --from /path/to/agent-run.json
```

生成语义评估提示：

```bash
npm run agent-run:judge -- --list
npm run agent-run:judge -- --case <caseId>
```

评估引擎和边界见 [`../eval/README.md`](../eval/README.md)。

## 5. 路由案例

`routing-cases.json` 保存不同自然语言任务的代表性输入和预期路由信息，包括：

- 主要和次要任务类型；
- 是否需要澄清；
- 分析深度；
- Focus（关注点）的语义；
- 必需数据；
- 默认不应获取的数据；
- 当前能力不足时需要公开的缺口。

路由案例中的 Focus 是语义参考，不是字符串白名单。测试不应要求 Agent 对新问题复述固定短语。

修改 `SKILL.md`、任务路由、数据路由或数据计划结构后，应同时检查这些案例。

## 6. 评估严格度

从确定性到主观性依次为：

1. TypeScript 数据模型和单元测试；
2. Tool 调用次数、禁止调用、来源位置和回答模式等结构化规则；
3. 外部评估模型依据语义标准给出的评分；
4. 人工或真实使用者对任务完成质量的判断。

前两类适合自动回归，后两类适合判断内容质量。不能用关键词命中代替语义正确性，也不能只凭一次主观评分修改整个 Skill 协议。

## 7. 固定样例维护

- 固定样例只保留代码真正使用的最小字段；
- 需要覆盖成功、空数据、部分数据和失败；
- 平台字段变化应先在适配层复现和修正；
- 不把真实 Cookie、用户信息或大段无关内容写入样例；
- 测试文件数和测试条数以实际命令输出为准，不在文档中维护；
- 测试生成的临时目录和真实 Agent 运行结果不得进入正式发布物。
